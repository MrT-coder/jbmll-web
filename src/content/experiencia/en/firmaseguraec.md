I designed and developed a complete alternative electronic-signature issuance
flow within a microservices architecture, aimed at a specific type of company.
The flow has issued more than 1,000 electronic signatures.

I implemented communication between microservices with Feign clients and HTTP
Interface (`HttpExchange`), and Pub/Sub messaging for asynchronous flows.

I built an AI-powered module using Spring AI that analyzes changes in the
company's API documentation and automatically generates update templates that
are emailed to partners, reducing manual communication effort.

I developed an internal transactional email module that sends branded,
template-based messages from the company's own infrastructure.

I implemented white-label branding for partners, serving each partner's own
assets through an image CDN built on Cloudflare R2.

I lead an agentic development workflow, driven by specifications and tests, with
a human-in-the-loop approach: quality is decided before writing code, not in the
pull request review.
